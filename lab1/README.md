Задания 4-7 Лабораторной работы №1 по Дискретной математике. На данный момент выполнены 4-7

**Описание**:

На вход даётся файл, содержащий формулу следующего формата:

> ($A [^] $B)

Можно использовать скобки, для констант и переменных (латинские буквы, регистр не важен) используется символ $. Операторы заключаются в квадратные скобки
Соответствие операторов:

[!] - НЕ (NOT) \
[\*] - И (AND) \
[!\*] - НЕ-И (NAND) \
[\+] - ИЛИ (OR) \
[!\+] - НЕ-ИЛИ (NOR) \
[^] - Исключающее ИЛИ (XOR) \
[=] - Эквиваленция (XNOR) \
[->] - Импликация \
[!->] - Коимпликация \

Для получения СДНФ используется флаг `--pdnf`, для СКНФ `--pcnf`, для отображения фиктивных переменных флаг '--fictive', а для других базисов (AND, OR, NOT; NAND; NOR; XOR, AND, 1 - Полином Жегалкина) `--different_basis`

**Компиляция**:

`gcc -Wall -Wextra *.c -o truth_table

**Пример использования**:

`./truth_table --pdnf --pcnf --fictive --different_basis file.txt`
