Задания 4-7 Лабораторной работы №1 по Дискретной математике.

На вход даётся файл, содержащий формулу следующего формата:

> ($A [^] $B)

Можно использовать скобки, для констант и переменных (латинские буквы, регистр не важен) используется символ $. Операторы заключаются в квадратные скобки
Соответствие операторов:

! - НЕ (NOT) \
\* - И (AND) \
!\* - НЕ-И (NAND) \
\+ - ИЛИ (OR) \
!\+ - НЕ-ИЛИ (NOR) \
^ - Исключающее ИЛИ (XOR) \
= - Эквиваленция (XNOR) \
-> - Импликация \
!-> - Коимпликация \
